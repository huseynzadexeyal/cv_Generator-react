# CV Yarat
React + Vite CV generatoru (3 şablon, ATS yoxlaması, PDF və Word export).

    npm install
    npm run dev      # development
    npm run build    # production (dist/)

Struktur: src/data.js (nümunə data), src/ats.js (ATS qaydaları), src/Paper.jsx (şablonlar), src/exportDocx.js (Word export), src/App.jsx (UI).
